# Update Policy

OPE uses a continuous update pipeline:

Official update -> research -> impact analysis -> affected modules -> change proposal -> implementation -> version bump -> changelog -> validation.

Maintain a source registry with URL, platform, publication/update date, checked date, affected modules, evidence level and implementation status.

Prioritize changes that affect discovery, crawling, indexing, retrieval, citations, rendering, accessibility, security, measurement or conversion.

Never silently overwrite a proven rule with a trend. Preserve history and mark superseded rules DEPRECATED.
