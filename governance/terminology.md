# Terminology

**Entity:** a uniquely identifiable person, organization, product, service, place or other real-world/digital concept.

**Presence:** the complete set of owned and third-party signals through which an entity can be discovered, understood, trusted and acted upon.

**Retrieval:** a system selecting information as evidence for an answer or task.

**Citation:** an explicit reference to a source used by an answer system.

**Grounding:** using retrieved source information to constrain or support an answer.

**Root cause:** the underlying condition responsible for an observed failure, not merely the visible symptom.

**Experience preservation:** improving implementation efficiency while maintaining approved visual and functional behavior.

AEO, GEO and LLMO are treated as optimization lenses within the broader presence system, not independent foundations.
