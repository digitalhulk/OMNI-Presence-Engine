# Audit Record Schema

Every finding should contain:

- id
- timestamp
- asset/property
- module
- symptom
- evidence
- evidence_level
- affected_users/systems
- dependency
- root_cause
- business_impact
- severity
- confidence
- priority
- recommended_fix
- validation_method
- regression_guard
- owner
- status
- source_refs

Priority should consider impact, confidence, effort, dependency and reversibility—not severity alone.
