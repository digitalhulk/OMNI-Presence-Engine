# Entity Model

An OPE entity record should model:

- canonical name
- entity type
- aliases
- identifiers
- owner
- official properties
- people/organizations
- products/services
- locations
- relationships
- attributes
- evidence sources
- freshness
- confidence

Relationship examples: owns, operates, provides, located-in, serves, sells, authored-by, reviewed-by, associated-with.

The entity model is the semantic backbone for search, AI retrieval, local discovery, content planning and trust.
