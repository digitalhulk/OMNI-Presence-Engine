# OPE Orchestrator v1

## Inputs

- entity and project configuration
- target URLs and properties
- market, language and device context
- business goals and conversion events
- connected data sources

## Execution

1. Build entity inventory.
2. Run technical discovery.
3. Query first-party search and analytics sources.
4. Query OpenSEO for SEO datasets.
5. Use Parallel AI for current web research, competitor discovery, source extraction and evidence.
6. Normalize all observations.
7. Run module checks.
8. Trace dependency graph.
9. Score and prioritize.
10. Generate an action plan.
11. Validate after implementation.
12. Register monitoring and regression checks.

## Guardrails

Credentials never enter repository content. Provider-specific measurements remain attributed to their provider. High-impact claims require stronger evidence. Destructive changes require explicit approval. Performance changes must preserve approved visual and functional behavior.

## Output

A run produces: inventory, evidence set, findings, root causes, scores, prioritized actions, validation criteria, monitoring plan and change log.
