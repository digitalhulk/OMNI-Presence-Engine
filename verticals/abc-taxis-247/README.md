# ABC Taxis 247 — OPE Reference Blueprint

ABC Taxis 247 is the reference vertical for a local, transactional transportation business.

## Entity graph
Business -> service -> vehicle -> driver -> route -> pickup -> destination -> date/time -> passengers -> luggage -> airport -> fare -> booking -> support.

## Presence surfaces
Website, local profiles/maps, search results, service/location pages, reviews, images, videos, social profiles, third-party mentions, booking flows and AI answer systems.

## Core journeys
1. Discover a taxi/airport transfer service.
2. Verify trust, availability, route and price information.
3. Compare options.
4. Book or contact.
5. Complete trip.
6. Review/refer/rebook.

## Measurement
Track discovery, calls, form submissions, bookings, qualified leads, conversion rate, acquisition cost, revenue, repeat use and attribution.

## Technical reference
Preserve the approved customer-facing design and functionality while improving delivery, rendering, accessibility, security, discoverability and measurement.

This folder is a vertical implementation of OPE, not a separate methodology.
