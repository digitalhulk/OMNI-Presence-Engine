# ABC Taxis 247 — OPE Reference Execution Blueprint v1

ABC Taxis 247 is the reference vertical for validating the generic OPE system.

## Entity model

Business, brand, service, vehicle, driver, pickup, destination, airport, route, fare, passenger, luggage, booking, support, service area and operating hours.

## Intelligence inputs

Parallel AI: live competitor research, local market research, current service information, source discovery and evidence collection.

OpenSEO: keyword research, SERP/rank context, competitor SEO signals, backlink signals, site audit data and supported AI-visibility measurements.

First-party: Search Console, Bing Webmaster, analytics, server/CDN logs, booking and conversion data where connected.

## Transaction journey

DISCOVER -> SERVICE UNDERSTANDING -> TRUST -> ROUTE/FARE INTENT -> BOOKING -> CONFIRMATION -> RIDE -> SUPPORT -> REVIEW -> REPEAT.

## Critical checks

- Local entity consistency
- Service-area coverage
- Airport and route intent coverage
- Booking page crawlability and indexability
- Mobile interaction and form accessibility
- Page performance without reducing visual quality
- Structured data correctness
- Review and reputation evidence
- Search and AI citation visibility
- Conversion tracking and attribution

## Success model

Visibility is not the final KPI. OPE evaluates the chain from qualified discovery through booking, completed service, repeat behavior and revenue.
