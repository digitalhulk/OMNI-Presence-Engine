# Official Source Registry — Baseline

This registry is the starting point for continuous updates. Re-check before making platform-specific claims.

## Google Search
Google Search Central documentation and Search status/update documentation are the primary sources for Google crawling, indexing, search and generative-search guidance.

## Bing
Bing Webmaster documentation is the primary source for Bing crawling, indexing, IndexNow, AI grounding and AI Performance reporting.

## OpenAI
OpenAI publisher/developer documentation is the primary source for ChatGPT search crawler and publisher guidance.

## Standards
W3C/WAI is the primary source for accessibility standards and guidance. IETF/RFC and relevant web platform specifications are preferred for protocol behavior.

## Research rule
Record the source URL, date checked, claim, affected OPE module, evidence level and resulting change. Community observations can generate hypotheses but do not override official documentation without validation.
