# Roadmap

## Phase 0 — Foundation
- repository governance
- architecture and terminology
- evidence policy
- scoring model
- update pipeline
- ABC Taxis 247 reference blueprint

## Phase 1 — Audit engine
- technical discovery
- crawl/index checks
- semantic/entity checks
- content/media checks
- accessibility checks
- performance checks
- security checks
- analytics and conversion checks

## Phase 2 — Visibility engine
- search visibility
- local visibility
- image/video visibility
- AI retrieval and citation readiness
- authority and reputation

## Phase 3 — Automation
- discovery collectors
- audit runners
- diagnosis and prioritization
- monitoring
- reporting
- regression detection

## Phase 4 — Continuous intelligence
- official platform update ingestion
- impact mapping
- controlled experiments
- versioned playbooks
- benchmark datasets
- automated validation

## Rule
No feature is considered complete until it has an owner, input/output definition, evidence level, measurement method, validation method and failure mode.
