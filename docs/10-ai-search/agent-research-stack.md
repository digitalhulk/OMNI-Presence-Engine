# AI Research Stack

OPE combines live web research with SEO/search measurements rather than treating AI visibility as a standalone content trick.

## Stack

`OPE Orchestrator`
`-> Parallel: live research / extraction / monitoring`
`-> OpenSEO: SEO datasets / rank / keyword / backlink / audit / AI visibility`
`-> First-party: GSC / Bing / analytics / server logs`
`-> Evidence Normalizer`
`-> Root-Cause Engine`
`-> Action Planner`
`-> Validation`

## Example workflow

1. Detect a visibility drop.
2. Pull first-party query/page evidence.
3. Pull OpenSEO competitive/rank context.
4. Use Parallel to research current SERP pages, competitor changes, official updates and relevant source material.
5. Normalize evidence.
6. Classify FACT / OBSERVED / ESTIMATE / HYPOTHESIS.
7. Trace symptom to root cause.
8. Produce a remediation plan.
9. Deploy and re-measure.
10. Record regression guard.

## Key rule

Do not ask one provider to answer a question it is not designed to measure. OPE is the orchestration and reasoning layer that combines specialized evidence sources.
